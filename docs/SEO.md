# SEO Architecture

1. **Dynamic Metadata**: Title, description, keywords, OpenGraph, and Twitter Cards generated per route.
2. **Indexing**: `/sitemap.xml` and `/robots.txt` dynamically generated.
3. **Structured Data**: JSON-LD Person and WebSite schemas embedded in `<head>`.
4. **Feeds**: `/feed.xml` provides RSS 2.0 article discovery.
