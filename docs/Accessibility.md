# Accessibility (WCAG AA Compliance)

1. **Keyboard Navigation**: Focus rings, skip links (`SkipToContent`), and `Escape`/`Enter` key handlers.
2. **Screen Readers**: Descriptive `aria-label`, `aria-expanded`, `aria-modal`, and `role` attributes across all components.
3. **Contrast Ratios**: Verified text-to-background contrast meeting WCAG AA 4.5:1 standards.
