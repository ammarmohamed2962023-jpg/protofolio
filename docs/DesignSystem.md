# Design System & Token Specifications

## Color Palette

- **Primary Background**: `#060912`
- **Secondary Background**: `#0d1117`
- **Cyan Accent**: `#00e5ff`
- **Blue Accent**: `#3b82f6`
- **Green Accent**: `#10b981`
- **Orange Accent**: `#f97316`

## Typography

- **Body Font**: Inter (`--font-inter`)
- **Mono Font**: JetBrains Mono (`--font-mono`)

## Component Tokens

- **Glass Cards**: `.glass-card` backdrop-blur-xl with subtle cyan borders.
- **Buttons**: `.btn-primary` gradient pill buttons with active scale transforms.
