# Security Policy

## Supported Versions

Only the latest version on the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this portfolio, please send an email to **ammar.mohamed.cs@gmail.com**.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any suggested fixes or mitigations.

We will acknowledge receipt of your report within 48 hours and work on a fix promptly.
