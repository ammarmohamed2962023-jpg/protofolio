# Contributing Guidelines

Thank you for considering contributing to this project!

## How to Contribute

1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/AmazingFeature`).
2. **Commit Changes**: Follow conventional commits (`git commit -m 'feat: Add some AmazingFeature'`).
3. **Verify Standards**: Ensure ESLint and test suites pass (`npm run lint && npm run test`).
4. **Push to Branch**: Push to your branch (`git push origin feature/AmazingFeature`).
5. **Open a Pull Request**: Submit a PR to the `main` branch with a clear description.

## Code Style & Guidelines

- Use ESLint rules configured in the project (`npm run lint`).
- Ensure all new components support keyboard accessibility and proper ARIA labels.
- Do not introduce dependencies without prior justification.
